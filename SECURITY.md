# Seguridad en OMEGA

## Estado

OMEGA no es un sistema operativo funcional todavía. No hay superficie de
ataque real porque no hay código ejecutable.

## Reportar vulnerabilidades

Cuando exista código ejecutable, se establecerá un canal de reporte.

Por ahora, si encuentras un problema en la documentación o en las
especificaciones, abre un issue público.

## Principios de seguridad

OMEGA aspira a:

- Mínimo privilegio.
- Aislamiento fuerte entre componentes.
- Capabilities explícitas.
- Sin autoridad ambiental.
- Verificabilidad.

Estos principios **no están demostrados**. Son objetivos de investigación.
