# Contribuir a OMEGA

## Estado del proyecto

OMEGA está en fase de construcción inicial. El repositorio se está creando
y la arquitectura todavía no está completamente especificada.

## Cómo contribuir

Por ahora, las contribuciones se limitan a:

1. Revisión de documentación existente.
2. Corrección de errores en documentación.
3. Propuestas de ADRs (Architecture Decision Records).
4. Revisión de especificaciones.

El código de kernel todavía no está abierto a contribuciones.

## Proceso

1. Abrir un issue describiendo la propuesta.
2. Esperar feedback.
3. Enviar un pull request.
4. Revisión.

## Reglas

- No inventar hechos.
- No afirmar que algo funciona sin evidencia.
- Separar hechos, hipótesis y decisiones.
- Documentar las decisiones importantes como ADR.

## Principio rector

> Conocer → comparar → experimentar → decidir → construir.
