# Código de Conducta

## Principios

- Respeto.
- Honestidad técnica.
- Transparencia.
- Colaboración.

## Comportamiento esperado

- Argumentar con evidencia.
- Reconocer errores.
- No atacar personas.
- No inventar hechos.

## Comportamiento inaceptable

- Acoso.
- Desinformación deliberada.
- Apropiación de trabajo ajeno.

## Aplicación

Los maintainers pueden moderar discusiones y bloquear cuentas si es necesario.
